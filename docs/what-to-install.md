# What to Install

Which components of offlinedatasci to install depends on your use case.
If you are justing using/teaching R or Python (not both) then only installing the files related to the language you need can save a lot of space and download time.
Below each component offered by offlinedatasci is listed along with some information on the cases where you might want to install it and the downloaded data sizes.

## R

Data size: ~300 MB

Install if you are using R.

## R packages

Data size: ~ 300 MB

Install if you are using R and want to have access to common data science packages.

## Python

Data size: ~120 MB

Instal if you are using Python

## Python Packages

Data size: ~400 MB

Install if you are using Python and want to have access to common data science packages.

## Lessons

Data size: ~150 MB

Install if you need direct access to lesson materials through your browser
